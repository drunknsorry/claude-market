# drunknsorry — Claude Code Plugin Marketplace

Plugin marketplace for Claude Code plugins by drunknsorry.

## Install

```
/plugin marketplace add drunknsorry/claude-market
```

## Available Plugins

| Plugin | Description |
|---|---|
| **wwsas** | Autonomous engineering council — design, build, ship, and self-improve. |

### Install a plugin

```
/plugin install wwsas@drunknsorry-claude-market
```
